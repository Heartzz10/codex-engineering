# 基线盘点与本包绑定

来源：用户本次批准的调研与实施约束；公共包只是工程工具及隔离样例，没有新的产品角色、权限服务、日志平台或供应商预算决定。本包配置不是其他项目的默认决定。

| 领域 | 直接复用 | 本次补充 | 项目边界 |
|---|---|---|---|
| UI | Q01～18、HTML/axe、运行测量、真实验收、已发布0.3.1 ui review | UI-1～4映射及项目绑定 | 具体设计/组件仍按原项目；直接继承review，不重复实现 |
| 交互 | 表单/异步约定与原样例浏览器驱动 | INT-1～4绑定与缺口门禁 | 去重、迟到响应、弹窗、编辑策略需各项目现有实现 |
| 错误 | 原样例HTTP/页面显示与runner | ERR-3统一安全转换并修复内部异常泄露 | 其余中文/恢复/结果未知仍需实际验收及审查 |
| 日志 | 项目已有日志库/运行环境 | 允许字段构造、敏感字段坏例；LOG-1～4绑定 | 本包没有业务日志存储；位置/权限/容量/期限待项目决定 |
| 权限 | 原checkAuthorization与assessCoverage | AUTH-1～4引用真实矩阵/AC并保留缺口 | 工程授权不代替业务账号/对象授权，不能自动设角色 |
| 数据/API | 原profile校验、样例输入/持久化与真实读回 | DATA-1～2绑定 | 并发策略/限制留原文，不新建数据框架 |
| 组织 | 原模块/构建/发布机制 | ARCH-1绑定已有依赖检查 | 本包未安装依赖检查器；unsupported明确保留 |
| AI/外部 | 原判断客户端、预算账本、材料检查 | AI-1～3绑定实际业务调用入口 | 本轮无供应商请求；业务预算/权限不由工程建议替代 |

本包实际可执行检查：`contracts` 运行 business-contracts 测试，包含真实隔离HTTP失败与正常保存读回；`baseline` 运行规则、runner、profile测试。ERR-3和本包隔离API的DATA-1已绑定实现/决策/必需检查；其余规则仍按项目具体对象保留待绑定。笔记样例登记 `api-contracts` 和 `browser-flow`，现已对非法输入不落盘、安全异常、迟到搜索、重复提交与请求重放、未知保存结果、长中文和并发持久化提供坏例/合法例及实际入口原件。UI-1～4、INT-1/2/4、ERR-1～4、DATA-1/2 的逐条结果须以已安装版本与最新AC评估为准；UI需要单条场景的测量及定向审查，整体UI质量仍受Q15/Q17未定约束。LOG-1～4和ARCH-1不借工程回执或静态关键词扫描凑通过，具体状态见[本轮交付](../PUBLIC-VALIDATION.md)。这不把样例业务套到其他项目。

工程规则修改使回执失效；AC 绑定必须把工程规则配置、对应实现和决策原文纳入原有 implementationRefs/dependencyRefs。人工规则核每个目标有效断言，不接受被target override覆盖掉的人工审查。

实施初始源码为开发0.1.0、已装独立0.3.0。启用预检发现其他对话已将日常升级到0.3.1，旧0.4.0候选未启用。最终以受核0.3.1完整文件集合加本次增量重建0.4.1，直接继承已发布UI review及检查器修复；其他未提交工作不整体发布。模块差异核对明确保留换行差异，不把LF/CRLF误当业务代码改变。
