# 业务权限规则：AUTH-1～4

防止无授权执行、本人权限扩大到他人、隐藏按钮代替授权及撤权失效。适用于业务账号、操作和数据对象；工程 check.effects/permissions 只限制工具执行，不授予业务权限。

项目沿用实际权限入口，把角色/属性×操作×数据范围、公开访问决定和撤权时效保存在原需求。配置仅引用该原文与现有测试/AC，不创建权限服务或猜角色。

从获批范围验证明确允许、未登录/未授权拒绝、同角色不同账号与本人/他人对象；绕过 UI 的受控接口须拒绝且数据未变化；撤权/换账号核新旧会话和缓存。用独立需求给测试预期，不能让错误实现生成自己的答案。

通过工程检查仍须现有真实验收与权限语义审查；缺账号、隔离条件或已确认矩阵标未验/待绑定。公开访问与共享对象只按项目明确决定，不能以规则例外扩大授权。参考 OWASP Authorization。
