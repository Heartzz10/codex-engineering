# UI 规则：UI-1～4

防止操作拥挤、用途不匹配、文字不可读和组件状态分裂。适用于有页面/控件的项目；源字段与例外在程序目录 `catalog/engineering-rules.json`。

复用现有 Q01～Q18、`ui prepare/source/assess`、布局测量及源码检查；不另建质量分类。项目绑定已有设计文档、间距值、布局模板、组件与例外。8px 仅是示例，不是默认值。

编码前读取项目原文与相关组件；实际输入/点击/等待/业务读回，并核宽窄屏、关键文字和主要操作。视觉协调及用途需要具名审查；自动测量通过不等于美观或业务通过。`ui review` 在包含它的版本中复用已有原件，未安装时由 Codex 按现有清单复核，不重复实现。

规则绑定到项目原 checks 与 AC；原生/设备缺适配标 unsupported，未知设计值标 needs_binding。允许文本省略须实际能取得全文；特定设计例外留项目出处。可参考 Carbon 方法与 APG，未选用的组件库不安装。
