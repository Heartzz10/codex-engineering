# 数据与接口规则：DATA-1～2

防止字段定义分散、非法输入越界、假保存成功及并发覆盖。适用于数据/API边界和持久化。

复用项目共用字段、校验库、事务/保存和冲突入口。类型、范围、必填、兼容策略及并发约定留项目原文，不强选框架。

DATA-1 的已登记检查应有合法、缺失、格式非法及业务含义非法案例；只过类型不证明业务合法。DATA-2 实际保存→刷新/重开→读回，并按既有并发规则核冲突；成功文字不能证明落盘。

现有接口通过适配保持兼容；没有并发能力或缺实际入口就保留未覆盖状态，不能自动降为不适用。规则工具复用 AC 逐目标验收；中文结果与冲突处置仍需项目审查。参考 OWASP 输入校验，不替代输出编码及数据库等专项保障。
