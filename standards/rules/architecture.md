# 代码组织规则：ARCH-1

防止通用组件依赖具体页面、模块绕过公共入口及依赖方向失控。适用于项目已定义模块边界。

复用现有构建/依赖检查；JS/TS 可按项目选 dependency-cruiser，Java 可选 ArchUnit，其他栈用现有合适工具。工具必须实际解析该栈的依赖；关键词搜索、文件名清单与结构字段齐全不能冒充依赖检查。

项目保存目录、公共入口、允许方向和限定例外的来源，规则绑定该检查的 ID、配置与实现文件；违规依赖应失败，合法方向应通过。没有适配显式标 unsupported/needs_binding，不整套安装候选。

公共包不新建依赖规则语言；绑定只承接既有工具输出。规则变化使旧回执过期；构建门禁需要项目明确接入，不保证约束绕过入口的命令。
